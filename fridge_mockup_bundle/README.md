# Холодильник — Handoff Bundle (Плотная компоновка)

Обновленный макет веб-интерфейса виртуального холодильника и мастера милпрепов с применением всех замечаний из `sugest.txt` и референса плотной компоновки.

## Состав архива

- `Холодильник.dc.html` — основной прототип в формате Claude Design / DC Component;
- `index.html` — копия для быстрого открытия в веб-браузере;
- `support.js` — рантайм dc-component (React 18 + Babel standalone);
- `uploads/claude-design-web-ui-spec.md` — спецификация UI/UX требований;
- `.thumbnail` — превью для Claude Design.

## Реализованные улучшения (по sugest.txt)

1. **Дисциплина цвета («одна роль на цвет»)**:
   - Тёмно-зелёный (`#1E5B3C`) — только основное действие (`Создать милпреп`, `Готовить →`, `Сохранить`, `Применить`);
   - Янтарь (`#C27803` / `#B45309`) — индикатор скорой порчи (0–2 дня);
   - Приглушённый серый (`#8A857B`) — просроченные продукты;
   - Обводка контура (`outline: 2px solid #1A1917`) + галочка `✓` — выбранное состояние (без паразитной заливки фона);
   - Цвет закреплен на левом ребре строки шириной 3 px (`border-left: 3px solid ...`).

2. **Экран 1: Плотный список по сроку годности вместо магазинной сетки**:
   - Естественная группировка: *«Срочно: сегодня и завтра»*, *«На этой неделе»*, *«Свежее и длительное хранение»*;
   - Вся строка является единой целью нажатия (клик — выбор/изменение количества, иконка ⓘ — карточка);
   - Миниатюра 40–44 px вместо громкой диагональной штриховки;
   - Чистая строка КБЖУ в `IBM Plex Mono`: `Б 20 · Ж 6 · У 0` без дублирования «на 100 г» в каждой строке;
   - Согласованные счетчики продуктов в шапке и подзаголовке.

3. **Экран 2: Переворот иерархии в сторону дозы и инсулина**:
   - Углеводы на 1 контейнер (`У 23,5 г`) и КБЖУ порции выведены крупным шрифтом как главный ориентир;
   - В режиме «Поровну» 4 идентичные строки объединены в одну сводную карточку `4 контейнера по ~295 г → У 23,5 г на порцию`;
   - Убран бесполезный 100% прогресс-бар в режиме «Поровну»;
   - Унифицирована терминология: «милпреп», «Милпрепы», «Создать милпреп».
